# 滑读 · Swipe Reader

一个面向「想读英文论文/报告/文章的人」和「想通过全英文章学英语的人」的外文阅读小工具：每段是一张卡片，**左滑看中文，右滑回英文**。

在线体验：https://zouyue123321.github.io/swipe-reader/ （手机上用 Safari 打开，「添加到主屏幕」即可像 App 一样使用）

## 产品思路

- **先硬读，再滑看中文**：默认只显示英文，读不懂的段落才左滑看译文，保留「自己读懂」的过程。
- **自主阅读率**：记录偷看了几段中文，计算自主阅读率，让进步看得见。
- **两种模式**：
  - 学英语模式：默认英文，逐段按需切换，统计自主阅读率；
  - 速读模式：面向读论文、报告的人，一键看全文中文，快速抓重点。
- **生词本**：点单词查释义，一键加入生词本；可搜索、点喇叭朗读，并显示这个词在哪几篇内置文章里出现过几次。
- **阅读统计**：阅读时长（只在阅读页、且有操作时计时）、连续天数、自主阅读率、已读段落，按 7天 / 月 / 年 看柱状图。数据只存在本机浏览器里。
- **首页继续阅读**：记住上次读到的文章和进度，文章库按分类筛选、显示每篇的阅读进度。

## 怎么用

1. 在首页选择一篇文章（标有 B1 / B2 / C1 难度）；
2. 逐段阅读英文，卡片左滑看中文，右滑回到英文；
3. 点击单词查看释义，可加入生词本；
4. 底部栏：首页 / 书库 / 搜索 / 生词本 / 统计；书库里的「粘贴我的英文文章」可以贴入自己的文本阅读。

纯静态网页（HTML + CSS + JS），无需安装，直接打开 `index.html` 即可运行。

界面：黑色顶部 + 橙色强调，书封为纯 CSS 绘制，不使用任何版权图片。
